FocusDeck browser sites

Tells FocusDeck when you switch to one of your X or docs sites, by category only. URLs, page titles and hostnames never leave this browser.

FocusDeck on this computer: http://127.0.0.1 or http://localhost, any port. Only if FocusDeck's server sets FOCUSDECK_SENSOR_TOKEN. It is kept in this browser profile and sent only to the URL above.

What it sends

When the active tab switches to a site on one of the lists FocusDeck gives it, and only for categories you designated in FocusDeck:

{"kind":"app-switch","app":"browser-x","via":"browser-extension"}

Nothing else. A switch to a site that isn't listed sends nothing. Consecutive switches within one category send one event. FocusDeck stamps the time when it arrives.
